# VaultRail Video Production

## Status: Requires External Recording

The MP4 video cannot be generated in this environment due to missing recording tools.

## Required for Recording

1. **Loom Mobile App** (Recommended)
   - Install from Play Store
   - Follow `recording-guide.md`
   - Record live dashboard at: https://vaultrail-dashboard.vercel.app/

2. **Alternative: Laptop + OBS**
   - Open dashboard on PC
   - Use OBS to screen record
   - Export as MP4

## Files Created

- `demo-script.md` - Scene-by-scene demo guide
- `pitch-script.md` - 2-minute pitch script
- `recording-guide.md` - Step-by-step Android instructions
- `description.txt` - YouTube/Loom description with disclaimer

## Video Specifications

- Format: MP4
- Resolution: 1920x1080 (16:9)
- Duration: 2-3 minutes
- Audio: Clear narration

## Disclaimer (must be included)

> VaultRail is currently a prototype. The dashboard is not connected to Solana, 
> and on-chain transactions have not been demonstrated.
